# 算法产物管理策略

## GitHub 保存什么

- 算法服务代码。
- systemd/init 部署模板。
- 配置样例。
- 验证方法。
- 交付记录。
- 训练和转换流程说明。

## GitHub 不保存什么

- 客户原始图片和视频。
- 设备抓拍历史图。
- SQLite 数据库备份。
- `.pt`、`.onnx`、`.rknn`、`.ai`、`.zip` 等模型或算法包二进制。
- SSH 密码、摄像头密码、客户内网密码。

## 模型包位置

当前模型包保存在本地桌面“算法包”目录。需要交付时从本地或设备侧取包，不通过 GitHub 分发。

如果后续需要多人协作保存模型版本，优先考虑 Git LFS 或对象存储，不要直接把大文件提交进普通 Git。
